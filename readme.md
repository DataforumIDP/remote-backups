# Система резервного копирования файлов

Скрипт для автоматического резервного копирования файлов с удаленного сервера по SSH или FTP. 

## Возможности

- Подключение к серверу по SSH или FTP
- Автоматическое сканирование папок с датами (формат DD_MM_YYYY)
- Создание ZIP-архивов с содержимым каждой папки
- Автоматическое удаление старых резервных копий
- Поддержка конфигурации через .env файл
- Планировщик автоматического запуска с настраиваемым интервалом
- Возможность указать время первого запуска

## Установка

1. Склонируйте репозиторий
2. Установите зависимости:
```bash
npm install
```
3. Скопируйте `.env.example` в `.env` и настройте параметры подключения:
```properties
SERVER_HOST=ip.адрес.сервера
SERVER_PORT=22
SERVER_USER=пользователь
SERVER_PASSWORD=пароль
SERVER_TYPE=ssh # или ftp
REMOTE_DIR=/путь/к/папке/на/сервере/
RETENTION_DAYS=90
INTERVAL=24 # Интервал между бэкапами в часах
START=23:59 # Время первого запуска в формате HH:mm
```

## Использование

1. Скомпилируйте TypeScript:
```bash
npx tsc
```

2. Запустите скрипт:
```bash
node dist/backup.js
```

Или используйте PowerShell скрипт:
```powershell
.\run-backup.ps1
```

## Структура проекта

- `src/backup.ts` - основной код скрипта
- `backups/` - папка для сохранения архивов
- `.env` - конфигурация подключения
- `run-backup.ps1` - скрипт для запуска в PowerShell

## Формат архивов

Архивы создаются в формате:
```
backup_YYYY-MM-DD_00-00-00.zip
```
Где YYYY-MM-DD - дата из имени папки на сервере.

## Хранение архивов

- Архивы хранятся в папке `backups/`
- Старые архивы автоматически удаляются после истечения срока хранения (RETENTION_DAYS в .env)
